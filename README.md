# open-apps

把常用的付費軟體做成自己和朋友能用的開源版本。每個 App 一個資料夾。大部分是網頁版，打開連結就能用；需要動到電腦檔案的（例如 Mac 清理）是 Mac App，要自己編譯。

| App | 對標 | 狀態 | 連結 |
|---|---|---|---|
| [課堂錄音](apps/class-recorder/) | Otter、Notta、Plaud | 第一版原型 | https://gop9632.github.io/open-apps/apps/class-recorder/ |
| [Mac 清理](apps/mac-cleaner/) | CleanMyMac | 第一版 | Mac App，見資料夾說明 |

規劃文件放在 `docs/plans/`。
