# 課堂錄音：產品與架構規劃

> 對標：Otter.ai、Notta、Plaud、Notion AI 會議記錄。目標是自己和朋友上課、開會都用得順的版本。
> 第一版原型在 `apps/class-recorder/`。價格都是 2026 年附近的公開定價約略值，以官網為準。

## 先講一個用詞

你寫的 text to speech 是「文字轉語音」（電腦唸字給你聽）。從其他需求看，你要的是反過來的 **speech to text，語音轉文字**（把老師講的話變成逐字稿）。原型照語音轉文字做，另外在「AI 整理重點」旁邊放了一顆「朗讀」按鈕，真的想聽電腦唸重點也可以。

## 一、六個需求怎麼做到

| # | 你的需求 | 做法 | 第一版原型 |
|---|---|---|---|
| 1 | 手機或電腦錄音 | 做成網頁 app（PWA），手機加到主畫面就像 app。錄音每 5 秒寫進裝置，當機只掉最後幾秒 | ✅ |
| 2 | 語音轉文字 | 錄完按「開始轉寫」，可選三種引擎（見第二節） | ✅ |
| 3 | 中文、英文、中英夾雜 | 語言設「自動」，加上每門課的**專有名詞詞表**，再用 OpenCC 轉成台灣繁體 | ✅ |
| 4 | 分辨聲音、鎖定老師 | 說話者分離 + 老師聲音樣本 + 「只看老師」（見第三節） | ✅ |
| 5 | 筆記分類 | 分類有課程、會議、專案三種，每段錄音可搜尋、改標題、移動分類 | ✅ |
| 6 | 錄電腦內建聲音 | 電腦版 Chrome／Edge 可錄「瀏覽器分頁」聲音（YouTube、線上課都在這），Windows 可錄整台電腦。Mac 錄 Zoom 這類 app 的聲音要做 Mac 版（見第四節） | 部分 ✅ |

## 二、轉寫引擎：三條路都留

你在 anthonys-whispr-flow 的 #6 已經用自己的聲音測過，**whisper.cpp + large-v3-turbo + 詞表**在你的 Mac 上準又快。那個結論直接沿用。差別是上課錄音很長（一兩小時），而且要分出誰在講話。

| 引擎 | 費用 | 分得出老師嗎 | 適合 |
|---|---|---|---|
| **Google Gemini** | 免費額度（錄音會被 Google 用來改進模型） | ✅ 可給老師聲音樣本，每週都標成「老師」 | **預設**。手機、朋友都能用 |
| OpenAI gpt-4o-transcribe-diarize | 約 US$0.36／小時（一學期 3 門課每週 3 小時，約 US$17） | ✅ 可給老師聲音樣本 | 想要付費、資料不被拿去訓練 |
| Groq whisper-large-v3-turbo | 免費額度每天約 8 小時 | ❌ | 只要逐字稿 |
| 你 Mac 上的 whisper.cpp | 免費、不上網 | ❌（之後可加） | 隱私、零成本 |

我的建議：**先用 Gemini 免費額度跑起來**，它免費又分得出老師。在意隱私的課改用 Groq 或 Mac 本機。等第二階段把本機的說話者分離（pyannote）接好，再讓 Mac 版走全本機。

兩個從 whispr-flow 實測搬過來的教訓：
1. **詞表要在辨識前給**。每門課的設定裡有詞表欄位，Groq 和本機引擎會把它放進提示詞（放最後，因為超過 224 token 會從前面砍）。Gemini 也會拿到詞表；OpenAI 分說話者的模型不吃提示詞。
2. **簡繁要處理**。Whisper 類模型常吐簡體，原型轉寫完一律跑 OpenCC 台灣用詞轉換，設定可關。

## 三、怎麼「定向老師」

老實說，手機麥克風做不到真正的「只收某個方向的聲音」。能做的是三層：

1. **錄的時候**：手機放講台附近或坐前排，影響最大。設定裡有降噪開關，教室吵時試，但老師離很遠時降噪可能把老師也壓掉，所以預設關。
2. **轉寫時分人**：模型把每段話標上說話者。沒有樣本時，**講最多話的人推定為老師**（上課時老師通常講七到九成）。
3. **老師聲音樣本**：每門課錄一次 8 秒老師講話（或從檔案選），之後每週轉寫都會固定標成「老師」。

看的時候勾「只看老師」，學生發問、旁邊聊天就收起來。認錯人時點名字就能切換。

## 四、平台：先網頁，之後補 Mac 版

| 平台 | 可以 | 不行 |
|---|---|---|
| 網頁（手機） | 錄麥克風、看筆記 | 錄手機內建聲音；iPhone 螢幕關掉可能停錄（原型已自動防休眠，第二階段實測） |
| 網頁（電腦 Chrome／Edge） | 麥克風、瀏覽器分頁聲音、兩者混錄；Windows 可錄整台電腦 | Mac 上錄其他 app 的聲音 |
| Mac 原生 app（第二階段） | 用 ScreenCaptureKit 錄任何 app 的聲音、本機 whisper.cpp 與說話者分離 | 要寫 Swift，你在 whispr-flow 已經走過簽章與權限流程 |

iPhone 的保險做法：用內建「語音備忘錄」錄，再到 app 按「匯入音檔」。螢幕關掉也不會斷。

## 五、你沒提到但很值得做的

**已經在原型裡**
- ★ **標記重點**：上課聽到「這個會考」按一下（電腦按空白鍵），時間點會留下來，AI 整理時也會參考
- 📷 **拍白板／投影片**：照片自動對到錄音時間，點照片跳到那段
- **點逐字稿跳播放**，播放時對應那句會亮起，1.25×、1.5×、2× 加速
- **逐字稿可以直接改字**
- **AI 整理重點**：一句話摘要、重點（附時間）、名詞解釋、作業考試期限、可能沒聽懂的地方、5 題複習問題。可選 OpenAI 或 Claude
- **匯出** Markdown、SRT 字幕、原始音檔，一鍵複製貼到 Notion
- **全部存在你的裝置**，不經過任何我們的伺服器

**第二階段建議**
1. **上課中即時字幕**：邊錄邊出字，外語課很有用
2. **跨週問答**：「老師哪一週講過 ANOVA？」直接問整門課的所有錄音
3. **匯入投影片 PDF**：自動抽出詞表，重點對到第幾頁
4. **行事曆自動分類**：照 Google 日曆判斷現在是哪堂課，錄音自動歸檔
5. **複習卡片**：從重點產生間隔複習卡（跟清單上的 F3 背單字共用）
6. **英文課中英對照**
7. **雲端同步與分享給同學**：要加帳號與後端，朋友共用一組 API key 才不會外流

## 六、朋友怎麼用

現在每個人要在設定填自己的 API key（只存在自己瀏覽器）。想讓朋友不用申請 key，就要加一個小後端（例如 Cloudflare Workers）代為呼叫並設邀請碼。這是第二階段的事。

## 七、法律提醒

錄課堂自己複習一般沒問題，但最好先跟老師說一聲。錄音和逐字稿涉及老師的著作權，不要公開散布。
