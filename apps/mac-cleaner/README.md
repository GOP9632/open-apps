# Mac 清理

對標 CleanMyMac 的免費開源版。可以清系統垃圾、找大型檔案、把 App 和它的殘留一起移除。

**安全第一：** 掃描只看不動；動手前一定先列出清單讓你確認；所有東西只移到垃圾桶，後悔可以放回原處；系統檔、密碼、雲端資料夾、郵件、照片圖庫一律不碰。完整規則見 [規劃文件](../../docs/plans/mac-cleaner.md)。

## 怎麼裝

1. 第一次要先裝 Xcode 指令列工具（只要一次）。打開「終端機」，貼上：
   ```
   xcode-select --install
   ```
2. 編譯：
   ```
   cd apps/mac-cleaner
   ./build.sh
   ```
3. 打開 `build/MacCleaner.app`。想放進應用程式資料夾就把它拖過去。

## 三個功能

| 畫面 | 做什麼 | 預設勾選 |
|---|---|---|
| 系統垃圾 | App 快取、記錄檔、開發工具暫存、下載的 .dmg／.pkg | 快取和記錄檔有勾；正在執行的 App 和安裝檔不勾 |
| 大型檔案 | 家目錄裡超過 50 MB～1 GB 的檔案 | 全部不勾 |
| 解除安裝 App | App 本體加上設定檔、快取、App 資料等殘留 | App 開著時不能移除 |

## 清完之後

東西都在垃圾桶裡。確認電腦和 App 都正常，再到 Finder 清空垃圾桶，空間才會真的空出來。
每次清理的紀錄存在 `~/Library/Application Support/MacCleaner/清理紀錄.log`。
